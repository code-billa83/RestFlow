# 🚀 Requestify (या आपका चुना हुआ नाम)

A sleek, lightweight, and modern API Testing Client built from scratch using **Next.js**, **Tailwind CSS**, and **TypeScript**. Designed for developers who want a fast, browser-based alternative to heavy desktop apps like Postman.

### ✨ Key Features
- **Method Selector:** Easily toggle between GET, POST, PUT, DELETE, etc.
- **Responsive UI:** Crafted with dynamic layouts that look great on any screen.
- **Fast & Minimalist:** No heavy installations, completely web-based and optimized.
